RP GROUP MANAGER — نسخه 1

قابلیت‌های این نسخه فقط این‌هاست:
1) ربات را به گروه اضافه کن و ادمین کامل بده.
2) در گروه بنویس: فعال
3) فقط مدیران گروه می‌توانند دستور «سکوت» را اجرا کنند.
4) روی پیام کاربر ریپلای کن و بنویس: سکوت
5) کاربر برای مدت نامحدود محدود می‌شود و پیام‌های بعدی او هم توسط ربات حذف می‌شوند.

نکته مهم:
- توکن را در فایل عمومی گیت‌هاب قرار نده.
- برای Runflare از Environment Variable با نام RUBIKA_TOKEN استفاده کن.
- ربات برای حذف پیام و محدودکردن اعضا باید دسترسی‌های لازم ادمینی را داشته باشد.

اجرای محلی در Pydroid:
    pip install -U rubka==7.1.13
سپس توکن را در main.py یا محیط متغیر RUBIKA_TOKEN قرار بده و:
    python main.py

اجرای Runflare:
- پروژه را در GitHub قرار بده.
- در Runflare یک سرویس Docker بساز.
- مخزن GitHub را به سرویس متصل کن.
- Environment Variable:
    RUBIKA_TOKEN = توکن ربات
- Deploy / Revert آخرین commit
- Container با Dockerfile خودش اجرا می‌شود.
